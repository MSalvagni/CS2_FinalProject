# General Inputs:
The application menu selections from the user to determine which operation to perform. Depending on the selected operation, the user may enter:
•	A patron ID to identify a library patron
•	A book title to check out or return a book
•	An author name to search for books
•	A genre selection to filter books by genre
The application also reads saved books, patron, and transaction information from text files when it starts.
General Outputs:
The application displays 
•	Book titles, authors, genres, availability, and book types
•	Patron IDs and names
•	Search results for authors and genres
•	Checkout and return confirmations or error messages
•	Transaction history, including checkout dates and due dates
•	Messages confirming that library information has been saved
Book, patron and transaction data are stored in text files so that information can be retained between program runs.
